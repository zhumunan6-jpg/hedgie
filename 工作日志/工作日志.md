# Hedgie 项目工作日志

## 项目目标

将原本偏预算管理的记账软件，逐步改造成更重视收入、支出、结余和长期存款目标的个人财务管理软件。

## 第一阶段：项目梳理与方向确认

### 已完成

- 梳理项目结构，确认项目是单文件离线 PWA。
- 确认核心代码集中在 `index.html`。
- 确认项目包含记账、月报、年度报告、同步和 Den 资产数据兼容能力。
- 明确产品方向：从预算型记账转向以收支记录和存款目标为核心。
- 明确当前优先保留记账和月报两个主要界面。
- 明确存款目标功能暂缓，后续再作为独立界面规划。

## 第二阶段：删除通知功能与预算展示

### 已完成

- 删除顶部通知铃铛按钮。
- 删除通知面板、通知徽章和通知交互逻辑。
- 删除内置提醒生成器，包括周期账单提醒、预算提醒、同步提醒和记账提醒。
- 删除自定义通知规则引擎及其条件计算逻辑。
- 删除通知相关 CSS、翻译文本、事件绑定和定时刷新任务。
- 删除月报中预算使用率、未设置预算、预算金额对比等展示。
- 将月报分类区域改为展示实际支出金额和分类支出占比。
- 保留底层预算字段和同步兼容数据，避免影响旧数据读取和同步。
- 更新 README、USER_GUIDE 和 CONTRIBUTING 中已移除功能的说明。

### 检查结果

- 内联 JavaScript 语法检查通过。
- 通知功能相关代码全局扫描无残留。
- Git diff 检查通过。
- 未改动收入录入和存款目标功能，等待后续阶段规划。

## 后续计划

## 第一阶段：数据结构、本地保存与旧数据清理

### 已完成

- 增加 `hedgie_data` 本地数据存储，核心业务数据在变更时立即保存，刷新或重新打开页面后可恢复。
- 收入记录继续使用 `income` 字段，并补齐收入来源、金额、日期、备注和周期字段；旧收入无日期时迁移到当前月份，零金额项不迁移。
- 增加按 `YYYY-MM` 保存的 `savingsTargets` 月度存款目标数据，并纳入本地保存和云同步载荷。
- 移除 `Savings` 支出分类、默认预算项目、分类选项和筛选按钮。
- 清理已有 `Savings` 支出预算、历史记录、归档记录和周期账单；Den 融资账户及储蓄目标主体保留，仅清空失效的分类关联。
- 云端数据应用、冲突比较和本地数据加载共用同一套迁移与清理逻辑，保留旧同步载荷兼容性。
- 修复旧同步路径中未定义的 `LOCKED_CATS` 引用。

### 检查结果

- 内联 JavaScript 语法检查通过。
- Node.js 模拟检查通过：本地保存、刷新恢复、旧收入迁移、零金额过滤、月度目标保存和 `Savings` 全量清理。
- `git diff --check` 通过。
- 未执行第二阶段的界面改造；收入录入窗口和目标进度展示按计划留到后续阶段。

- 在记账界面增加收入录入能力。
- 继续识别并处理其他不符合产品方向的预算描述。
- 设计独立的存款界面和长期存款目标功能。
- 每完成一个阶段，继续在本文档中追加记录。

## 第二阶段：改造第一个界面

### 已完成

- 将支出和收入录入改为桌面端并排、移动端上下排列的对称窗口。
- 支出窗口保留分类、金额、商家、备注、日期、周期账单和 Den 关联能力。
- 增加无分类收入窗口，支持收入来源、金额、备注、日期和周期收入。
- 增加收入记录列表，支持收入编辑、删除和停止周期收入。
- 删除首页按所选月份显示的支出指标，改为累计收入、累计支出和总存款概览。
- 总存款按全部活动记录和归档记录计算：累计收入减累计支出，不受月份选择器影响。
- 增加本月存款目标设置和本月存款进度卡片，目标按 `YYYY-MM` 保存。
- 本月存款按当前自然月收入减支出计算；未设置目标时显示空状态，负数时显示红色金额和 0% 进度，超额时进度条封顶但百分比保留实际完成度。
- 增加周期收入模板的本地保存、云同步载荷、启动自动补记和重复防护。
- 保留月报、冬眠视图、首页支出记录编辑删除和 Den 功能主体不变。

### 检查结果

- 内联 JavaScript 语法检查通过。
- Node.js 逻辑检查通过：旧收入无日期迁移到当前月份、零金额收入过滤、月度目标清理、周期收入自动补记和重复防护。
- `git diff --check` 通过。
- 检查确认总存款使用活动记录与归档记录，月度存款只使用当前自然月数据。
- 检查确认收入数据无分类字段，周期收入模板进入本地快照和云同步冲突比较。
- 桌面端和移动端布局通过 CSS 结构检查；收入窗口未引入类别选择。

### 遗留事项

- 月报页面的指标、交易记录窗口和年度收入统计仍按计划留到第三阶段处理。

## 第三阶段：改造第二个界面（月报）

### 已完成

- 月报指标改为月收入、实际支出、本月存款和本月存款目标及进度。
- 月收入和本月存款按月报当前选择的月份计算，不再使用全部历史收入。
- 存款目标进度支持未设置目标、负数存款、未达标、达标和超额完成状态；负数进度条保持为 0%，金额显示为红色。
- 保留按类别统计支出，并移除月报底部交易记录卡、分类筛选、交易记录渲染和相关状态变量。
- 年度收入改为按实际收入记录统计；年度支出分类统计和冬眠视图继续保留，年度柱状图同时包含归档支出。
- 月份和年份选择器补充收入、存款目标及归档数据对应的月份和年份。
- 清理月报交易记录窗口专用翻译文本，保留首页支出记录列表的编辑和删除能力。

### 检查结果

- 两段内联 JavaScript 语法检查通过。
- Node.js 逻辑检查通过：多月份收入、支出、本月存款、负数进度、目标百分比边界和年度实际收入统计。
- `git diff --check` 通过。
- 月报交易记录窗口、分类筛选状态和专用渲染函数残留扫描通过。
- CSS 结构检查确认指标卡可换行，适配移动端；首页记录列表和冬眠视图代码未被删除。

### 遗留事项

- 当前环境未提供浏览器自动化依赖，未执行真实浏览器截图检查；本阶段已完成静态结构和逻辑验证。
